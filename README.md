# ladder-who5

Open part of [108psy.com](https://108psy.com): a free AI-guided self-help
diagnostic for women in Kazakhstan (Russian, Kazakh, English).

This repository contains:

- `src/who5.mjs`: WHO-5 Well-Being Index scoring and bands (rule-based, no AI). MIT.
- `content/who5.{en,ru,kk}.json`: the five WHO-5 items, answer scale and result messages in three languages. CC BY 4.0.
- `content/ladder-questions.{en,ru,kk}.json`: question templates of the Ladder method (goal, number of steps, "I" step, takeaway). CC BY 4.0.
- `test/`: unit tests. Run `npm test` (Node 20+).

## How it is used in the product

A woman answers the five WHO-5 items for the last two weeks. The score is computed
by `who5Score` and mapped to one of three bands by `who5Band`. The result message
for the band is fixed text, not generated by a language model. A language model
only explains the woman's Ladder in plain language within safety rules; the
wellbeing check and the crisis block do not depend on it.

## Not a medical device

The score is not a diagnosis. The service does not replace a doctor.
